# Domain Feature Modules
Domain-specific UI components, state, and sub-routing:
- `auth/`: User registration, login, phone/email OTP verification
- `booking/`: Turf slot grid, 5-hour duration logic, add-on selectors, checkout
- `dashboard/`: Booking history, rescheduling, cancellation/refund workflows
- `admin/`: Venue owner tools (slot blocking, maintenance, dynamic pricing rules)
